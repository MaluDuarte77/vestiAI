# VestiAI

Cole qualquer link de roupa. Veja no seu corpo. Converse com uma IA antes de comprar.

# Problema
Comprar roupas online é uma experiência baseada em tentativa e erro.

# Solução
O VestiAI cria um gêmeo digital do usuário e oferece recomendações personalizadas de tamanho, estilo e caimento.

Avatar 3D personalizado
